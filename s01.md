# s01: agent loop 

傳prompt給LLM --> LLM決定是否需要tools --> 重複透過tools回傳結果給LLM, 直到不再需要調用tools --> 結束執行

```
核心程式碼:
def agent_loop(messages: list):
    while True:
        # 創建對話, 設定模型
        response = client.messages.create(
            model=MODEL, system=SYSTEM, messages=messages,
            tools=TOOLS, max_tokens=8000,
        )

        # Append assistant turn
        messages.append({"role": "assistant", "content": response.content}) # 將回覆加至對話紀錄中, 保持上下文完整

        # If the model didn't call a tool, we're done
        tool_calls = [
            block for block in response.content if block.type == "tool_use" 
        ] # 偵測是否還需要使用到tool
        if not tool_calls:
            return # 沒的話就結束回應

        # Execute each tool call, collect results
        results = [] # 儲存多個tool執行的結果
        for block in tool_calls: # 呼叫tools(如果有的話)
            print(f"\033[33m$ {block.input['command']}\033[0m") # 輸出將要做的事情
            output = run_bash(block.input["command"]) # 執行bash並取得執行結果
            print(output[:200]) # 輸出執行結果
            results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": output,
            })

        # Feed tool results back, loop continues
        messages.append({"role": "user", "content": results})
```

步驟: 

step 1: 輸入prompt `history.append({"role": "user", "content": query})`


step 2: 傳送message + 工具定義給LLM `response = client.messages.create(...)`


step 3: 紀錄模型回覆, 並檢查是否還需要調用tools `tool_calls = [...] | if not tool_calls: return`


step 4: 執行tools `results.append(...)`


step 5: 將結果回傳message, 再回到step2 `messages.append({"role": "user", "content": results})`
